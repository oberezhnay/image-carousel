# Image Carousel

Слайдер на Vue 3. Завантажує зображення з API `picsum.photos`, дозволяє відмічати улюблені зображення та зберігає вибір у LocalStorage.


## Live Preview
  - [DEMO LINK](https://image-carousel-seven-eta.vercel.app/)

## Запуск локально.

### 1. Clone the repository

```
git clone https://github.com/oberezhnay/image-carousel.git
cd image-carousel-vue
```

### 2. Install dependencies

```
npm install
```

### 3. Run the project locally

```
npm run dev
```
